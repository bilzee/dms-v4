# Story 10.2: Email Notification Admin Config UI

## Status
Ready

## Story
**As an** admin,
**I want** to configure email notification settings (enable/disable, priority routing, digest options) from the admin panel,
**so that** I can control the email notification channel without modifying environment variables.

## Acceptance Criteria

1. **Email channel card** - New "Email" channel card in the Channels tab of `/admin/settings/notifications`
2. **Email toggle** - Switch to enable/disable email notifications globally
3. **Email priority selector** - PrioritySelector component (reused from push/in-app) for email priority routing
4. **Digest toggle** - Switch to enable daily digest mode for non-critical email notifications
5. **Digest time picker** - Time input for digest delivery time (HH:MM), visible when digest is enabled
6. **Routing summary** - Email row added to the "Current routing summary" preview in Priority Rules tab
7. **Persistence** - All email settings save/load via existing notification-config API
8. **Defaults and reset** - Email section resets to defaults (disabled, CRITICAL+HIGH) on "Defaults" button
