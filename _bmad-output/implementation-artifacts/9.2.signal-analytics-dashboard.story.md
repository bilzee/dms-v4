# Story 9.2: Signal Analytics Dashboard UI

## Status
Ready

## Story
**As a** coordinator,
**I want** a visual analytics dashboard showing signal trends, resolution metrics, and entity hotspots,
**so that** I can quickly assess operational health without reading raw data.

## Acceptance Criteria

1. **Analytics page** - New page at `/coordinator/analytics` accessible to COORDINATOR and ADMIN roles
2. **Date range selector** - Toggle between 7d, 30d, 90d ranges, updates all charts
3. **Volume over time chart** - Line chart showing signal creation count per day, colored by `signalReason`
4. **Resolution velocity chart** - Horizontal bar chart showing median hours-to-resolve per reason
5. **Priority distribution chart** - Donut/pie chart showing CRITICAL/HIGH/MEDIUM/LOW breakdown
6. **Top entities table** - Sorted table of entities by unresolved signal count with entity name, type, count, and highest priority
7. **Role engagement summary** - Card-based summary showing signal count and resolution rate per role (ASSESSOR/RESPONDER/DONOR/COORDINATOR)
8. **Loading and error states** - Skeleton loaders while fetching; error display on API failure
9. **Responsive layout** - Charts reflow on mobile; table scrolls horizontally
