# Story 9.3: Signal Analytics Export

## Status
Ready

## Story
**As a** coordinator,
**I want** to export signal analytics data as CSV and Excel files,
**so that** I can share reports with stakeholders and archive historical data.

## Acceptance Criteria

1. **Export API endpoint** - `GET /api/v1/signals/analytics/export?range=7d&format=csv` returns downloadable file
2. **CSV format** - Flat table with columns: date, signalReason, priority, entityName, entityType, roleName, createdAt, resolvedAt, resolutionHours
3. **Excel format** - Same data in `.xlsx` with formatted headers, auto-width columns, and a summary sheet with aggregated metrics
4. **Filter support** - Same filters as analytics API: `range`, `role`, `incidentId`, `entityId`, `signalReason`
5. **Filename convention** - `signal-analytics-{range}-{YYYY-MM-DD}.{ext}`
6. **Performance** - Export of 10k rows completes in <5s
7. **Auth** - Restricted to COORDINATOR and ADMIN roles

## Tasks / Subtasks

- [ ] **Task 1: Export Service** (AC: 2, 3, 6)
  - [ ] Create `src/lib/services/signal-analytics-export.service.ts`
  - [ ] `exportSignalsAsCsv(filters)` — queries raw signals with joins (entity, user role), streams to CSV string via string concatenation (no external lib needed for CSV)
  - [ ] `exportSignalsAsExcel(filters)` — queries raw signals, builds workbook with `exceljs` (already in deps)
  - [ ] Excel workbook: Sheet 1 "Raw Data" with all signal rows; Sheet 2 "Summary" with aggregated counts, resolution rates, velocity by reason
