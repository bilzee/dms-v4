→ Key Differences — Admin Users Table

  • Card wrapper uses consistent rounded-lg border shadow-sm instead of varying card styles
  • SearchToolbar integrates search, filters, and action buttons in a single unified toolbar row
  • Table headers styled with text-xs font-medium uppercase tracking-wider for better hierarchy
  • Actions column uses DropdownMenu pattern with labeled items, icons, and separators
  • Search input has proper focus ring (ring-2 ring-primary/20) for accessibility
  • Filter selects use consistent dt-select styling with custom chevron instead of browser default
  • Built-in pagination footer with page info text and numbered page buttons
  • Toolbar action button ("Add User") right-aligned for consistent layout across all tables

→ Key Differences — Coordinator Donors Table

  • Filter toggle buttons replaced by structured <select> dropdowns in the DataTable toolbar
  • Status rendering standardized: icon+text replaced by consistent badge pill (success/warning colors)
  • Type badges maintain custom colors (blue/green/purple/orange) via column-level render config
  • SearchToolbar provides searchable=true with integrated search input, replacing no-search current state
  • Filter dropdowns declared via filters=[{key, label, options}] prop instead of ad-hoc toggle buttons
  • Row actions use DropdownMenu with labeled items ("Edit Donor", "View Details") instead of bare edit button
  • StatCardGrid remains outside DataTable as page-level layout (not migrated into the table component)
  • Consistent pagination footer with page count and navigation controls

→ Key Differences — Coordinator Entities Table

  • selectable=true adds built-in checkbox column with header select-all toggle for the Assign tab
  • Selected rows highlighted with subtle bg-primary/5 background color for clear visual feedback
  • Footer shows selection count (2 of 4 users selected) with batch action button
  • expandable=true adds expand/collapse arrow per row, with renderExpanded detail panel
  • Expanded row shows additional entity details (capacity, dates) in a sub-row with distinct background
  • Tab-based layout retained at page level; each tab renders its own DataTable with different configuration
  • Entity type badges use consistent color mapping: CAMP=blue, WAREHOUSE=orange, DISTRIBUTION_POINT=purple
  • Empty role state uses italic placeholder text ("None assigned") instead of an empty cell
