Section 01

StatCard

Unified metric/KPI card for all DRMS dashboard pages. One component to replace 16 ad-hoc variations across 14 source files.

Purpose

Every dashboard in DRMS renders metric cards -- small panels that display a label, a numeric value, and optionally an icon, a description, or a trend indicator. Today each page builds its own inline MetricCard, KpiCard, or hand-coded <Card> with inconsistent spacing, sizing, and dark-mode support.

The unified StatCard component replaces all of these with a single, well-tested, theme-aware implementation that ships five visual variants out of the box.

Design Philosophy

Vertical hierarchy. The label sits above the value, not beside it. The eye reads top-to-bottom naturally: what this is, then how much, then context. Generous spacing between layers prevents the card from feeling cramped. Minimal decoration -- no colored icon circles, no gradient backgrounds on generic cards -- lets the number itself carry visual weight.

Section 02

Design Rules

Icon placement: top-right only

Size h-4 w-4 (16px). Color text-muted-foreground. No colored icon backgrounds. No circular containers. The icon is a quiet contextual hint, never the focal point.

Value: text-2xl font-bold tracking-tight

Always 24px bold with tight tracking. Never smaller in a grid row. The value is the primary visual element and must be the same size whether the card sits alone or in a 4-column grid.

Label: text-sm font-medium text-muted-foreground

14px, medium weight, muted color. Sits directly above the value with mt-2 (8px) spacing between label and value. Never bold, never dark.

Spacing: p-6 (24px) inside

p-6 padding on all sides. mt-2 between label and value. mt-3 between value and trend row. The generous padding is intentional -- cards should breathe.

Colored backgrounds: status-aware only

Reserved for verification queue cards, active incidents, or role-specific status indicators. Never for generic metrics (total users, total commitments). Use 5% opacity tint on background, 15% opacity tint on border.

Trend indicators: diagonal arrows

Use ArrowUpRight / ArrowDownRight (diagonal), never TrendingUp / TrendingDown. Size h-4 w-4. Color: emerald-600 for positive, red-600 for negative. Neutral: em-dash, muted color.

Dark mode: mandatory for every variant

All five variants and the loading skeleton must render correctly in dark mode. Tinted backgrounds increase to 8% opacity. Borders to 20%. Cards use --card background from the shadcn dark token set.

Centered text with the value ABOVE the label (inverted hierarchy). Designed for peer comparison / ranking contexts where the value is a rank position or percentile, and the label describes what the rank represents. An optional badge below provides secondary context.

Section 04

Component API

interface StatCardProps { label: string value: string | number description?: string icon?: React.ComponentType<{ className?: string }> severity?: "info" | "success" | "warning" | "danger" | "critical" variant?: "default" | "tinted" | "compact" | "centered" trend?: { value: number label: string } loading?: boolean className?: string } type SeverityLevel = "info" | "success" | "warning" | "danger" | "critical"
Prop Type Default Description
label string -- Displayed above the value. Required.
value string | number -- The primary metric. Formatted by the parent (e.g. "1,284", "94.1%", "#3"). Required.
description string undefined Secondary text below the value. Muted color, 13px.
icon React.ComponentType undefined Lucide icon component. Rendered 16x16, top-right, muted color.
severity SeverityLevel undefined Maps to tint color: info=blue, success=green, warning=amber, danger=red, critical=purple.
variant "default" | "tinted" | "compact" | "centered" "default" Controls padding, font size, and layout direction.
trend { value: number, label: string } undefined Positive number = green up arrow. Negative = red down arrow. Zero = neutral dash.
loading boolean false Renders skeleton placeholders matching the variant structure.
className string undefined Merged via cn() for external overrides.

Section 06

StatCardGrid

A layout helper that provides consistent grid spacing and responsive breakpoints for dashboard metric rows. Wraps StatCard instances in a CSS Grid container.

interface StatCardGridProps { children: React.ReactNode columns?: 2 | 3 | 4 className?: string } // Usage <StatCardGrid columns={4}> <StatCard label="Total Donors" value={1284} icon={Users} /> <StatCard label="Active Incidents" value={12} icon={AlertTriangle} /> <StatCard label="Verified Today" value={156} icon={CheckCircle} /> <StatCard label="Pending" value={23} icon={Clock} severity="warning" variant="tinted" /> </StatCardGrid>

Grid Implementation

// StatCardGrid.tsx export function StatCardGrid({ children, columns = 4, className }: StatCardGridProps) { return ( <div className={cn( "grid gap-4", columns === 2 && "grid-cols-1 md:grid-cols-2", columns === 3 && "grid-cols-1 md:grid-cols-2 lg:grid-cols-3", columns === 4 && "grid-cols-1 md:grid-cols-2 lg:grid-cols-4", className )} > {children} </div> ) }
