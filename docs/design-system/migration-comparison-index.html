How to Read These Comparisons

LEFT
Current / Original Implementation
Rendered components copied directly from the existing DRMS codebase. Uses ad-hoc patterns (raw shadcn Table, hand-built card loops, inline grids).
RIGHT
Target Migration with DataList
Equivalent UI built with the DataList family (DataTable, DataCardList, DataCardGrid). Uses declarative column/row configs and shared infrastructure.

Both sides render from identical mock data so that visual parity and behavioural differences are immediately apparent.

DataList Component API Summary

Component Key Prop Type Description
DataTable columns* ColumnDef<T>[] Column definitions (header, cell accessor, sorting, width)
data* T[] Array of row data objects
sortable boolean Enable column-header sorting
filterable boolean Show the global search / filter bar
pagination { pageSize } Pagination controls beneath the table
DataCardList data* T[] Array of card data objects
renderCard* (item: T) => ReactNode Render function for each card
expandable boolean Allow cards to expand on click
renderExpanded (item: T) => ReactNode Content shown when a card is expanded
filterable boolean Show the filter / search bar
DataCardGrid data* T[] Array of card data objects
renderCard* (item: T) => ReactNode Render function for each card
columns number Grid column count (default responsive)
gap string Tailwind gap class, e.g. "gap-4"
filterable boolean Show the filter / search bar
All (shared) loading boolean Show skeleton loading state
emptyMessage string Message when data array is empty
onRowClick (item: T) => void Click handler for rows / cards

* = required  ·  All other props are optional. Full TypeScript definitions are in the DataList spec.
