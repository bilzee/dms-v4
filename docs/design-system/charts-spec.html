Problems Identified

!

No centralized chart colors

Each component hardcodes its own colors. Changing the palette requires editing every file independently.

!

No shared chart options

Font sizes, grid colors, tooltip styles are duplicated across files with subtle inconsistencies.

!

Chart.js registration per-file

ChartJS.register() called in each component instead of once at app initialization.

!

Custom CSS bars -- inconsistent

Mix of bg-gray-200 track + colored fill. Inconsistent heights, border-radius, gap spacing across files.

!

No dark mode support in Chart.js

Hardcoded RGB colors do not adapt to dark theme. Grid lines and labels remain light-mode only.

Section 03

Decision: Standardize on Chart.js

Chart.js is already the primary chart library. No need to switch. The strategy is to create centralized configuration files and a reusable ProgressBar component, then migrate existing code incrementally.

Section 06

Chart Patterns

1

Always use chart-config colors

Never hardcode RGB values inline. Import from chart-config.ts and use getChartColor() to resolve light/dark variant.

2

Use getDefaultChartOptions() as base

Every chart starts with shared options (font, grid, tooltip). Override specific properties per chart type if needed.

3

Detect dark mode via useTheme()

Pass isDark to all chart config functions. This adapts grid lines, tick labels, and tooltip styling automatically.

4

Use ProgressBar for simple metrics

If data is a single percentage or ratio, use ProgressBar instead of a full Chart.js bar chart. Reserve Chart.js for multi-point or multi-series data.

5

Register Chart.js once

Import chart-registration.ts in your app layout or root. Never call ChartJS.register() inside individual chart components.

Component API

ProgressBar

interface ProgressBarProps { value: number // 0-100 variant?: 'default' | 'success' | 'warning' | 'danger' | 'gradient' size?: 'sm' | 'default' | 'lg' showLabel?: boolean label?: string className?: string }
PropTypeDefaultDescription
valuenumber--Progress value 0-100. Required. Clamped to valid range.
variant'default' | 'success' | 'warning' | 'danger' | 'gradient''default'Color variant. Maps to primary, green, amber, red, or gradient fill.
size'sm' | 'default' | 'lg''default'Height: 6px (sm), 8px (default), 12px (lg).
showLabelbooleanfalseShows percentage text to the right of the label row.
labelstringundefinedCustom label text shown above the bar. Replaces percentage if showLabel is true.
classNamestringundefinedMerged via cn() for external overrides.

Chart Config Functions

FunctionParamsReturnsDescription
getChartColorcolor, isDark?stringResolves a CHART_COLORS entry to the correct light/dark RGBA value.
getDefaultChartOptionsisDark?ChartOptionsBase options: responsive, font family, grid colors, tooltip style.
getBarChartOptionsisDark?ChartOptionsBar-specific: extends default with bar percentage, category percentage.
getRadarChartOptionsisDark?ChartOptionsRadar-specific: extends default with scale config, point style.
